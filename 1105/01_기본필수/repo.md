
# Day14 이미지 분류 모델 학습 및 성능 비교 보고서

## 1. 실습 개요

본 실습은 제공된 정상 이미지 데이터를 활용하여 3개 클래스를 분류하는 딥러닝 모델을 학습하고, 하이퍼파라미터 변경에 따른 성능 차이를 비교하는 것을 목적으로 한다.

PyTorch 기반 CNN 모델을 사용하였으며, 사전 학습된 교육용 Backbone의 가중치는 고정하고 마지막 분류 계층인 Head만 학습하였다. 학습에는 Train 데이터를 사용하고, 모델 선택 및 성능 평가에는 Validation 데이터를 사용하였다. Test 데이터는 실험 과정에서 사용하지 않았다.

## 2. 모델 및 실험 환경

### 2.1 데이터 전처리

- 데이터 로딩: `torchvision.datasets.ImageFolder`
- 입력 이미지 크기: 32 × 32
- 이미지 채널: RGB 3채널
- 정규화 및 텐서 변환: `transforms.ToTensor()`
- 학습 데이터: `data/train`
- 검증 데이터: `data/valid`
- 검증 데이터 개수: 9개
- Test 데이터 사용 여부: 미사용

### 2.2 모델 구조

CNN 기반의 간단한 이미지 분류 모델을 구성하였다.

| 구성 요소             | 주요 역할          |
| ----------------- | -------------- |
| Conv2d            | 이미지 특징 추출      |
| BatchNorm2d       | 특징값 정규화        |
| ReLU              | 비선형성 추가        |
| MaxPool2d         | 특징 맵 크기 축소     |
| AdaptiveAvgPool2d | 특징 맵 크기 조정     |
| Flatten           | 특징 맵을 1차원으로 변환 |
| Linear            | 3개 클래스 분류      |

사전 학습된 Backbone은 고정하고 마지막 Linear 계층만 학습하도록 설정하였다. 이를 통해 전체 모델을 다시 학습하는 대신 분류 Head를 중심으로 학습을 진행하였다.

### 2.3 학습 설정

- Optimizer: AdamW
- Loss Function: CrossEntropyLoss
- 평가 지표: Accuracy, Macro F1
- 모델 선택 기준: Validation Loss 최소값
- 학습 환경: CPU 기반 PyTorch

## 3. 하이퍼파라미터 변경 실험

모델의 학습 결과에 영향을 주는 Learning Rate, Weight Decay, Epoch를 변경하여 총 3회의 실험 결과를 비교하였다.

| 실험   | Learning Rate | Weight Decay | Epoch |
| ---- | ------------- | ------------ | ----- |
| 실험 1 | 0.005         | 0.0001       | 20    |
| 실험 2 | 0.01          | 0.0          | 8     |
| 실험 3 | 별도 확인 필요      | 별도 확인 필요     | 50    |

※ 실험 3의 Learning Rate와 Weight Decay는 실제 실행 코드 확인 후 기입해야 한다.

### 3.1 하이퍼파라미터 변경 목적

**Learning Rate**

모델의 가중치가 학습 과정에서 얼마나 큰 폭으로 업데이트되는지를 결정한다. 학습률이 너무 크면 최적값을 지나칠 수 있고, 너무 작으면 학습 속도가 느려질 수 있다.

**Weight Decay**

가중치가 지나치게 커지는 것을 억제하는 정규화 기법이다. 과적합을 줄이는 데 도움을 줄 수 있다.

**Epoch**

전체 학습 데이터를 반복해서 학습하는 횟수이다. Epoch가 증가하면 학습 기회가 늘어나지만, 검증 성능이 반드시 향상되는 것은 아니다.

## 4. 실험 결과

### 4.1 성능 비교

실험 실행 결과 세 가지 설정 모두 동일한 검증 성능을 기록하였다.

| 평가 항목          | 실험 1  | 실험 2  | 실험 3  |
| -------------- | ----- | ----- | ----- |
| Accuracy       | 1.0   | 1.0   | 1.0   |
| Macro F1       | 1.0   | 1.0   | 1.0   |
| Best Epoch     | 20    | 8     | 50    |
| Validation 데이터 | 9개    | 9개    | 9개    |
| Test 사용 여부     | False | False | False |

### 4.2 결과 분석

세 실험 모두 Accuracy 1.0, Macro F1 1.0을 기록하였다.

Accuracy가 1.0이라는 것은 검증 데이터 9개를 모두 정확하게 분류했다는 의미이다. Macro F1 역시 1.0으로 나타나, 평가에 포함된 세 클래스의 분류 성능이 해당 검증 데이터에서 모두 완벽하게 측정되었다.

Best Epoch는 각각 20, 8, 50으로 차이가 있었다. 이는 각 실험에서 Validation Loss가 가장 낮았던 학습 시점이 달랐다는 것을 의미한다.

따라서 최종 분류 결과는 동일하지만 학습 과정과 모델의 예측 점수에는 차이가 있을 가능성이 있다.

다만 현재 확인된 결과에는 Validation Loss와 평균 예측 확률이 포함되어 있지 않으므로, 어느 실험의 모델이 더 안정적이거나 우수한지는 추가적인 비교가 필요하다.

## 5. 결과물 및 시각화

학습 및 평가 과정에서 다음 결과물을 생성하도록 구성하였다.

| 파일명                   | 내용                               |
| --------------------- | -------------------------------- |
| `metrics.csv`         | Accuracy, Macro F1, Best Epoch 등 |
| `metrics.json`        | 평가 지표 JSON 저장                    |
| `history.csv`         | Epoch별 Validation Loss           |
| `predictions.csv`     | 이미지별 실제 라벨, 예측 라벨, 신뢰도           |
| `confusion.csv`       | 클래스별 혼동행렬                        |
| `project_error_*.png` | 오분류 이미지 최대 8개                    |
| `project_cam.png`     | Grad-CAM 시각화 이미지                 |

특히 Grad-CAM을 활용하여 모델이 특정 클래스를 예측할 때 반응한 이미지 영역을 시각적으로 확인할 수 있도록 하였다.

Grad-CAM은 모델의 판단에 영향을 준 특징 영역을 이해하는 데 도움을 주지만, 해당 영역이 예측의 실제 원인임을 증명하거나 예측의 정확성을 보장하지는 않는다.

## 6. 실험의 한계점

첫째, 검증 데이터가 9개로 매우 적다는 한계가 있다. 적은 데이터에서는 일부 이미지의 예측 결과만으로도 평가 지표가 크게 달라질 수 있다.

둘째, 세 실험 모두 Accuracy와 Macro F1이 1.0으로 나타나 성능 지표만으로 하이퍼파라미터에 따른 차이를 구분하기 어려웠다.

셋째, Test 데이터를 사용하지 않았으므로 새로운 데이터에 대한 일반화 성능은 아직 확인되지 않았다.

넷째, 교육용 사전 학습 가중치를 사용하였으므로 현재 결과를 실제 환경의 이미지 분류 성능으로 일반화하기에는 추가 검증이 필요하다.

## 7. 개선 방향

1. 검증 데이터의 수를 늘려 평가 결과의 신뢰성을 높인다.
2. 별도의 Test 데이터를 최종 평가에 사용하여 일반화 성능을 확인한다.
3. Validation Loss와 평균 예측 확률을 함께 기록하여 실험 간 차이를 비교한다.
4. 클래스별 Precision, Recall, F1-score 및 혼동행렬을 분석한다.
5. Learning Rate와 Weight Decay를 단계적으로 변경하여 최적의 학습 설정을 탐색한다.
6. Grad-CAM 결과를 확인하여 모델이 이미지의 적절한 영역에 반응하는지 분석한다.

## 8. 결론

본 실습에서는 CNN 기반 이미지 분류 모델을 구성하고, 사전 학습된 Backbone을 고정한 상태에서 분류 Head를 학습하였다. 또한 Learning Rate, Weight Decay, Epoch 등의 하이퍼파라미터를 변경하여 총 3회의 실험을 수행하였다.

그 결과 세 실험 모두 Validation 데이터 9개에 대해 Accuracy 1.0과 Macro F1 1.0을 기록하였다. 이는 현재 검증 데이터에서 모든 이미지를 정확하게 분류했다는 것을 의미한다.

다만 검증 데이터의 수가 적고 세 실험의 평가 지표가 동일하므로, 특정 하이퍼파라미터가 더 우수하다고 결론 내리기는 어렵다.

향후 검증 데이터 확대, Validation Loss 비교, 별도 Test 데이터 평가 등을 통해 모델의 일반화 성능을 추가로 확인할 필요가 있다.
